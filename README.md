This project follows an iterative development approach, where each milestone delivers a fully functional application with new features and improvements.

The project begins as an implementation of a semantic search inspired by the book: *Build an LLM Application (from Scratch)* by Hamza Farooq. Building on these foundations, it will gradually evolve into a production-style Hotel Search Engine that combines semantic search, retrieval-augmented generation (RAG), and modern LLM techniques with front-end and back-end parts.
