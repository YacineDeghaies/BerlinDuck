# Hotel Search Copilot

## Goal

Build a clean, tested hotel semantic-search package.

## Rules

- Work on one milestone at a time.
- Explain important changes simply.
- Do not add FastAPI, Streamlit, databases, LLMs, or Docker yet.
- Use clear Python with type annotations.
- Keep preprocessing, similarity, and ranking separate.
- Return unique hotels, not duplicate reviews.
- Add tests for every important behavior.

## Verification

Before finishing Milestone 1, run:

- `pytest`
- `ruff check .`
- `mypy src`
